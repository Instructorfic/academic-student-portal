## Fuentes principales de la unidad

### Joyanes Aguilar (2020) — fuente principal

**Joyanes Aguilar, L. (2020).** *Fundamentos de programación:
algoritmos, estructuras de datos y objetos* (5.ª ed.). McGraw-Hill
Interamericana. ISBN: 978-607-15-1468-4.

La **referencia principal recomendada** para esta unidad. Sustenta:
computadora, lenguajes de programación, algoritmos, programas,
relación entre problema-algoritmo-programa, abstracción, resolución de
problemas, herramientas para representar algoritmos, e introducción al
pseudocódigo y a los diagramas de flujo.

### Cairo Battistutti (2015) — metodología algorítmica

**Cairo Battistutti, O. (2015).** *Metodología de la programación:
algoritmos, diagramas de flujo y programas* (3.ª ed.). Computec.

**Fuente prioritaria para 1.3 y 1.5** (representación de algoritmos y
resolución de problemas). Particularmente útil para establecer la
secuencia problema → análisis → algoritmo → representación → programa.
Aunque desarrolla metodología de programación con mayor profundidad,
en esta unidad solo se utilizan sus elementos introductorios — la
metodología formal se desarrolla en la Unidad III.

### Levine Gutiérrez (1994) — fundamentos de computación

**Levine Gutiérrez, G. (1994).** *Introducción a la computación y a la
programación estructurada* (2.ª ed.). McGraw-Hill. ISBN:
978-968-422-511-4.

Fuente complementaria para conceptos introductorios de computación y
del marco conceptual de la unidad. No se utiliza para introducir
anticipadamente las estructuras de control de unidades posteriores.

## Fuentes de apoyo conceptual

### Kernighan y Ritchie (1991)

**Kernighan, B. W., & Ritchie, D. M. (1991).** *El lenguaje de
programación C* (2.ª ed.). Prentice-Hall Hispanoamericana. ISBN:
968-880-205-0.

Su valor en esta unidad es **conceptual e histórico**, no como libro
principal para enseñar C: relación entre lenguaje y programa,
naturaleza de un lenguaje de programación, transición entre algoritmo
y código. No se introducen todavía tipos de datos, operadores,
variables, estructuras de control ni funciones.

### Stroustrup (2000)

**Stroustrup, B. (2000).** *The C++ Programming Language* (3rd ed.,
Special Edition). Addison-Wesley. ISBN: 0-201-70073-5.

Uso breve y conceptual, principalmente para distinguir programa y
lenguaje de programación. No se utiliza como fuente principal de
algoritmos en esta unidad.

## Fundamentación académica externa

### Wing (2006) — pensamiento computacional

**Wing, J. M. (2006).** Computational Thinking. *Communications of the
ACM*, 49(3), 33–35. DOI:
[10.1145/1118178.1118215](https://doi.org/10.1145/1118178.1118215).

Fundamenta el uso pedagógico de abstracción, descomposición,
razonamiento sistemático y resolución de problemas. El pensamiento
computacional funciona como marco pedagógico de apoyo.

## Recurso técnico/didáctico

**Scratch Foundation.** *Scratch: Imagine, Program, Share*.
<https://scratch.mit.edu/>. Recurso complementario, no constituye
bibliografía académica principal. Únicamente cuando se use como
puente visual entre algoritmo y programa.
