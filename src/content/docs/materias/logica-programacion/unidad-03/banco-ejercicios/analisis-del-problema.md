## Actividad guiada — Identificación de datos de entrada y resultados

**Modalidad:** actividad guiada en clase.

**Propósito:** identificar la información que debe proporcionar el
usuario y la información que debe producir un algoritmo.

**Antes de empezar debes conocer:** el concepto de algoritmo, el
concepto de dato y el concepto de resultado.

### Problema

Una tienda desea obtener el importe total de una compra a partir del
precio de un producto y la cantidad de unidades adquiridas.

### Qué debes hacer

1. Lee la definición del problema e identifica la información que debe
   proporcionar el usuario y la información que debe producir el
   algoritmo.
2. Completa las tablas de datos de entrada y resultados esperados:

   | Dato | Tipo | Descripción |
   | --- | --- | --- |
   | | | |

   | Resultado | Tipo | Descripción |
   | --- | --- | --- |
   | | | |

3. Para cada elemento indica su nombre, tipo de dato y descripción.
4. Identifica las restricciones: ¿qué valores no tendrían sentido para
   el precio? ¿La cantidad de unidades puede tener parte decimal?
   ¿Puede ser cero?

No desarrolles el pseudocódigo.

### Criterios de revisión

- [ ] Identifica correctamente los datos de entrada.
- [ ] Identifica correctamente el resultado esperado.
- [ ] Asigna un tipo de dato adecuado a cada elemento.
- [ ] Describe correctamente la función de cada dato.

## Actividad guiada — Identificación de datos conocidos y no conocidos

**Modalidad:** actividad guiada en clase.

**Propósito:** distinguir la información que proporciona el problema de
la información que debe proporcionar el usuario.

### Problema

Una empresa desea calcular el salario semanal de un trabajador a partir
del número de horas trabajadas y el pago correspondiente a cada hora.

La empresa establece que el pago por hora es de **85.00** unidades
monetarias.

Las horas trabajadas deben expresarse como un número entero mayor que
cero.

### Qué debes hacer

1. Analiza la información proporcionada en el problema.
2. Clasifica cada dato como **dato conocido**, **dato de entrada** o
   **resultado esperado**, y completa la tabla:

   | Información | Clasificación | Tipo de dato | Justificación |
   | --- | --- | --- | --- |
   | Pago por hora | | | |
   | Horas trabajadas | | | |
   | Salario semanal | | | |

3. Indica qué información debe proporcionar el usuario y qué
   información debe calcular el algoritmo.

No desarrolles el pseudocódigo.

### Criterios de revisión

- [ ] Clasifica correctamente cada elemento como dato conocido, dato de
  entrada o resultado esperado.
- [ ] Justifica cada clasificación con la información del problema.
- [ ] Distingue la información que debe solicitarse al usuario de la que
  ya proporciona el problema.
