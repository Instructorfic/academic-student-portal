## Contexto

A partir de [5. Constantes y variables](/materias/logica-programacion/unidad-02/05-constantes-y-variables/).

## Instrucciones

Para cada problema, identifica qué datos podrían considerarse variables y cuáles constantes, y explica brevemente tu decisión.

**A.** Calcular el área de un círculo.

**B.** Calcular el costo de un producto con un impuesto fijo.

**C.** Calcular el pago de un préstamo utilizando una tasa establecida.

## Producto esperado

Para cada uno de los tres problemas: lista de datos identificados, clasificación como variable o constante, y justificación breve.

## Criterio de logro

Identifica correctamente al menos dos datos por problema, clasifica cada uno como variable o constante de forma consistente con si su valor puede cambiar dentro de esa solución específica, y justifica la clasificación en al menos una línea por dato.
