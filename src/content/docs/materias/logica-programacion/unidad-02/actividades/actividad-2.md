**Modalidad:** individual.

## Contexto

A partir de [2. Expresiones](/materias/logica-programacion/unidad-02/02-expresiones/).

## Instrucciones

Para cada situación, sigue la secuencia **problema → datos → operación → expresión → resultado (cuando sea posible)**:

1. Calcular el área de un rectángulo. Datos: `base`, `altura`.
2. Calcular el costo de varios productos. Datos: `cantidad`, `precio`.
3. Calcular el promedio de tres calificaciones. Datos: `calificacion1`, `calificacion2`, `calificacion3`.
4. Determinar si una persona es mayor de edad. Dato: `edad`.
5. Determinar si una persona es mayor de edad y tiene identificación. Datos: `edad`, `tieneIdentificacion`.

Para cada situación, escribe explícitamente los datos identificados, la expresión construida y, cuando la situación proporcione valores concretos, el resultado de evaluarla.

## Producto esperado

Cinco expresiones construidas, cada una con sus datos identificados y, cuando aplique, su resultado.

## Criterio de logro

Las cinco expresiones utilizan correctamente los datos indicados y el operador adecuado para la operación solicitada (aritmética en 1–3, relacional en 4, relacional combinada con lógico en 5).
