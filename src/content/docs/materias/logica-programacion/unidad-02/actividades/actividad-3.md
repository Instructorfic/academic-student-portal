## Contexto

A partir de [3. Operadores](/materias/logica-programacion/unidad-02/03-operadores/).

## Instrucciones

Para cada expresión, identifiquen:

1. los operandos;
2. los operadores;
3. el tipo de expresión (aritmética, relacional o lógica);
4. el resultado (si cuentan con valores suficientes para evaluarla).

```text
8 + 5

20 - 7

precio * cantidad

edad >= 18

calificacion1 + calificacion2

edad >= 18 Y tieneIdentificacion
```

## Producto esperado

Tabla de análisis con las cuatro columnas (operandos, operadores, tipo de expresión, resultado) para las seis expresiones.

## Criterio de logro

Identifica correctamente los operandos y operadores de las seis expresiones, clasifica correctamente cada una como aritmética, relacional o lógica, y evalúa correctamente las que cuentan con valores suficientes.
