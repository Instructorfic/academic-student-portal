Esta ruta no pretende que leas libros completos. Su propósito es orientar la consulta de fuentes académicas confiables para consolidar los conceptos de esta unidad. No es necesario leer todas las fuentes de principio a fin: consulta la lectura indicada, identifica los conceptos señalados, compáralos con los ejemplos trabajados en clase y elabora tus propias explicaciones. Una definición encontrada en un libro no sustituye la comprensión del concepto — debes poder explicarlo con tus propias palabras y aplicarlo a un problema sencillo.

## Ruta general de aprendizaje

```text
INFORMACIÓN → DATOS → TIPOS DE DATOS → IDENTIFICADORES
   → VARIABLES / CONSTANTES → OPERADORES → EXPRESIONES
   → FUNCIONES MATEMÁTICAS → RESOLUCIÓN → COMPROBACIÓN
```

## Lectura 1 — Datos y tipos de datos

**Fuente principal:** Joyanes Aguilar (2020), 3.5 Datos, tipos de datos y operaciones primitivas; 3.5.1 Datos numéricos; 3.5.2 Datos lógicos; 3.5.3 Datos tipo carácter y tipo cadena.

**Propósito:** comprender que la información de un problema debe representarse mediante datos y que estos poseen diferentes tipos.

**Preguntas de lectura:** ¿qué es un dato? ¿qué es un tipo de dato? ¿por qué diferentes tipos de información requieren diferentes formas de representación? ¿puede un mismo valor representar información distinta según el contexto?

## Lectura 2 — Expresiones

**Fuente principal:** Joyanes Aguilar (2020), 3.7 Expresiones y operadores; 3.7.1 Expresiones aritméticas.

**Propósito:** comprender cómo se combinan datos mediante operaciones para obtener un resultado.

**Preguntas de lectura:** ¿qué es un operando? ¿qué es un operador? ¿qué es una expresión? ¿cómo puedo transformar una operación de un problema en una expresión que pueda ser representada por un algoritmo?

## Lectura 3 — Operadores

**Fuente principal:** Joyanes Aguilar (2020), 3.7.1 Expresiones aritméticas, 3.7.3 Expresiones lógicas. **Fuente de apoyo:** Cairo Battistutti (2015), 1.3.3 Operaciones aritméticas, 1.3.4 Expresiones lógicas.

**El estudiante debe reconocer:**

- Aritméticos: `+` `-` `*` `/` `%`
- Relacionales: `<` `>` `<=` `>=` `==` `!=`
- Lógicos: `Y`/`AND`, `O`/`OR`, `NO`/`NOT`

La notación podrá variar dependiendo de la herramienta utilizada.

**Preguntas de lectura:** ¿qué operación representa cada operador y qué tipo de resultado produce?

## Lectura 4 — Identificadores, constantes y variables

**Fuente principal:** Joyanes Aguilar (2020), 3.6 Constantes y variables; 3.6.1 Declaración de constantes y variables. **Fuente de apoyo:** Cairo Battistutti (2015), 1.3.2 Identificadores, constantes y variables.

**Modelo conceptual:**

```text
Identificador → nombre utilizado para referirse a un elemento
Variable      → elemento cuyo valor puede cambiar
Constante     → elemento cuyo valor permanece fijo
```

**Preguntas de lectura:** ¿cómo puedo representar de manera clara la información que necesita mi algoritmo? ¿cuándo conviene utilizar una variable y cuándo una constante?

## Lectura 5 — Funciones matemáticas

**Fuente principal:** Joyanes Aguilar (2020), 3.8 Funciones internas; 3.8.1 Funciones matemáticas.

**El estudiante debe reconocer aplicaciones como:** raíz cuadrada, valor absoluto, potencia, redondeo y otras funciones matemáticas básicas pertinentes.

**Preguntas de lectura:** ¿qué operaciones matemáticas no puedo expresar únicamente utilizando los operadores básicos?

## Lectura 6 — Resolución de expresiones

**Fuente principal:** Joyanes Aguilar (2020), 3.7.2 Reglas de prioridad; 3.7.4 Reglas generales de prioridad y asociatividad.

**El estudiante debe comprender:** prioridad de operadores, asociatividad, uso de paréntesis, evaluación paso a paso.

**Ejemplo:** `5 + 3 × 2` se resuelve primero como `3 × 2 = 6`, después `5 + 6 = 11`. En cambio, `(5 + 3) × 2 = 16`.

**Preguntas de lectura:** ¿cómo puedo determinar de manera sistemática el resultado de una expresión?

## Lectura 7 — Representación mediante pseudocódigo

**Fuente:** material didáctico elaborado para la materia (ver
[8. Herramientas de compilación](/materias/logica-programacion/unidad-02/08-herramientas-de-compilacion/)).

**Propósito:** relacionar los elementos estudiados con su representación mediante pseudocódigo.

**El estudiante debe poder representar:** datos, variables, constantes, operaciones, expresiones y resultados.

**Herramienta:** PSeInt o equivalente. La actividad se entiende como comprobación y ejecución del pseudocódigo, y no como enseñanza de un lenguaje de programación.

## Lectura 8 — Diagramas de flujo y comprobación

**Fuente:** material didáctico de la materia.

**Propósito:** relacionar la representación textual del pseudocódigo con una representación gráfica mediante diagramas de flujo (entrada → proceso/operación → salida).

**Preguntas de lectura:** ¿cómo puedo representar visualmente la secuencia de operaciones que realiza un algoritmo?

## Lectura 9 — Integración de conceptos

**Lectura:** revisión selectiva de las lecturas 1 a 8. No se incorpora una lectura extensa nueva.

**Modelo integrador:**

```text
Situación → información necesaria → datos → tipos de datos
   → variables/constantes → operadores → expresiones
   → funciones matemáticas → resolución → pseudocódigo
   → diagrama de flujo → comprobación
```

**Pregunta integradora:** ante una situación sencilla, ¿cómo puedo determinar qué información necesito, cómo representarla y qué operaciones debo realizar para obtener el resultado?

## Qué no necesitas estudiar todavía

Para mantener el alcance de esta unidad, en esta etapa no es necesario profundizar en: sintaxis de C, C++, Java, Python u otro lenguaje de programación; programación orientada a objetos; estructuras de decisión; ciclos; arreglos; matrices; estructuras de datos; modularización; depuración formal; planes de pruebas; ni una metodología formal de resolución de problemas. Estos contenidos se abordarán progresivamente en las unidades correspondientes (principalmente en la Unidad III y la Unidad IV).

## Producto de lectura recomendado

Después de completar la ruta, elabora una síntesis personal de una página, "De la información al resultado", que explique con tus propias palabras: qué es un dato y un tipo de dato, qué es un identificador y qué convenciones de nomenclatura existen, qué distingue a una variable de una constante, qué es un operador y cómo se clasifica, qué es una expresión, cómo se aplica la jerarquía de operadores y la asociatividad al resolver una expresión, para qué sirve una función matemática, y cómo se comprueba un resultado con una herramienta. No se evalúa la capacidad de copiar definiciones textuales.

## Resultado esperado

Al finalizar esta ruta deberías poder explicar y demostrar la siguiente cadena:

```text
¿Qué información tengo? → ¿Qué tipo de dato representa? → ¿Cómo la identifico?
   → ¿Es variable o constante? → ¿Qué operación necesito? → ¿Qué operadores utilizo?
   → ¿Necesito una función matemática? → ¿Cómo construyo la expresión?
   → ¿Cómo la resuelvo? → ¿Cómo la represento? → ¿Cómo compruebo el resultado?
```

La meta de esta unidad no es que memorices definiciones. La meta es que puedas representar la información de un problema sencillo y operar con ella de forma precisa.
