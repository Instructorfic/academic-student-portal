**RA relacionado:** RA2.6, RA2.8. **Contenido:** 2.2.2 Uso de herramientas de compilación para resolución de expresiones.
**Modalidad:** individual.

## Objetivo

Representar una operación mediante pseudocódigo y comprobar el resultado utilizando PSeInt o una herramienta equivalente.

## Problema

Calcular el costo total de una compra.

Datos:

```text
cantidad
precio
```

## Instrucciones

1. Identifica los datos de entrada y el tipo de cada uno.
2. Construye la expresión que calcula el costo total.
3. Resuelve la expresión manualmente para un ejemplo propio (elige valores concretos de `cantidad` y `precio`).
4. Escribe el pseudocódigo correspondiente y ejecútalo en PSeInt (o una herramienta equivalente).
5. Compara el resultado obtenido por la herramienta con tu resultado manual.

## Entregable

1. Identificación de datos.
2. Tipo de cada dato.
3. Expresión utilizada.
4. Pseudocódigo.
5. Resultado esperado (calculado manualmente).
6. Resultado obtenido (mediante la herramienta).
7. Conclusión de la comprobación: ¿coinciden ambos resultados? Si no coinciden, explica qué corregiste.

**Evidencia:** solución entregada en Moodle (código U2-L01), con enlace al repositorio cuando el docente lo indique.

## Criterio de logro

El pseudocódigo entregado corresponde exactamente a la expresión y a los datos descritos, y el resultado obtenido mediante la herramienta coincide con el resultado calculado manualmente.
