**RA relacionado:** RA2.6, RA2.8. **Contenido:** 2.2.2 Uso de herramientas de compilación para resolución de expresiones.
**Modalidad:** individual.

## Objetivo

Construir una solución algorítmica sencilla utilizando información, expresiones y representación gráfica.

## Problema

Calcular el promedio de tres calificaciones.

Datos:

```text
calificacion1
calificacion2
calificacion3
```

## Instrucciones

1. Identifica los datos de entrada y el tipo de cada uno.
2. Construye la expresión para calcular el promedio.
3. Representa la solución en pseudocódigo.
4. Representa la misma solución mediante un diagrama de flujo.
5. Ejecuta el pseudocódigo en PSeInt (o una herramienta equivalente) y compara el resultado con el que calculaste manualmente para al menos un ejemplo propio.

## Entregable

1. Identificación de datos.
2. Tipo de cada dato.
3. Expresión para calcular el promedio.
4. Pseudocódigo.
5. Diagrama de flujo.
6. Resultado esperado (calculado manualmente).
7. Comprobación mediante un ejemplo, ejecutado en la herramienta.

**Evidencia:** solución entregada en Moodle (código U2-L02), con enlace al repositorio cuando el docente lo indique.

## Criterios para los laboratorios 1 y 2

| Criterio | Qué se revisa |
| --- | --- |
| Datos | Identifica correctamente la información necesaria |
| Expresión | Representa correctamente la operación |
| Representación | El pseudocódigo (y, en este laboratorio, el diagrama de flujo) corresponden a la solución |
| Comprobación | El resultado obtenido coincide con el resultado esperado |

## Criterio de logro

El pseudocódigo y el diagrama de flujo entregados corresponden exactamente entre sí y con la expresión descrita, y el resultado obtenido mediante la herramienta coincide con el resultado calculado manualmente para el ejemplo propuesto.
