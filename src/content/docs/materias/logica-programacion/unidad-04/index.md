## La pregunta de la unidad

En la Unidad III aprendiste a pasar de un problema a una propuesta
algorítmica verificada y documentada. Todos esos algoritmos ejecutaban
sus instrucciones una sola vez y en el mismo orden. Esta unidad
responde:

> **¿Con qué estructuras se controla el orden en que se ejecutan las
> instrucciones de un algoritmo, y cómo se elige la adecuada para cada
> problema?**

## Resultados de aprendizaje de la unidad

Al finalizar esta unidad podrás:

| ID | Resultado de aprendizaje |
| --- | --- |
| RA4.1 | Utilizar instrucciones de entrada y salida para obtener datos del usuario y presentar resultados legibles, en el orden correcto y con mensajes que indiquen qué se solicita y qué se muestra |
| RA4.2 | Resolver problemas cuya solución es una secuencia fija de instrucciones (fórmulas encadenadas, porcentajes, cálculo inverso, descomposición con división entera y residuo) y reconocer cuándo una secuencia no basta |
| RA4.3 | Construir condicionales simples y dobles a partir de una condición expresada con operadores relacionales y lógicos |
| RA4.4 | Construir condicionales múltiples para seleccionar una opción entre varias a partir del valor de una variable |
| RA4.5 | Construir condicionales anidadas cuando una decisión depende del resultado de otra |
| RA4.6 | Resolver problemas que requieren decisiones, eligiendo el tipo de condicional adecuado y probando cada rama |
| RA4.7 | Construir ciclos `Mientras` controlados por una condición que se evalúa antes de cada repetición |
| RA4.8 | Construir ciclos `Repetir` que se ejecutan al menos una vez y terminan cuando se cumple una condición |
| RA4.9 | Construir ciclos `Desde` controlados por un contador con valor inicial, valor final y paso |
| RA4.10 | Resolver problemas que requieren repetición (contadores, acumuladores, valores máximo y mínimo), justificando la estructura repetitiva elegida |
| RA4.11 | Integrar estructuras secuenciales, condicionales y repetitivas en una solución completa, documentarla y exponerla |

## Qué vas a estudiar

Esta unidad cubre los contenidos oficiales del programa correspondientes
a la Unidad IV:

```text
4.1 Estructuras secuenciales
    4.1.1 Instrucciones de entrada/salida
    4.1.2 Resolución de problemas
4.2 Estructuras condicionales
    4.2.1 Simples
    4.2.2 Dobles
    4.2.3 Múltiples
    4.2.4 Anidadas
    4.2.5 Resolución de problemas
4.3 Estructuras repetitivas
    4.3.1 Mientras
    4.3.2 Repetir
    4.3.3 Desde
    4.3.5 Resolución de problemas
```

La numeración salta de 4.3.3 a 4.3.5 tal como aparece en el programa
oficial.

## El caso de la unidad: Cafetería El Byte

Los tres laboratorios y el proyecto trabajan sobre el mismo caso: una
cafetería pequeña dentro de una facultad (negocio ficticio) que hoy cobra
con calculadora y notas a mano. Laboratorio por laboratorio construirás
su programa de caja: primero el ticket de un pedido, después las reglas
de cobro y al final el cierre de caja de un turno completo.

| Código | Producto | Precio (IVA incluido) |
| ---: | --- | ---: |
| 1 | Café americano | $25.00 |
| 2 | Capuchino | $38.00 |
| 3 | Sándwich de pollo | $55.00 |
| 4 | Agua embotellada | $15.00 |

## Qué queda fuera de esta materia

Quedan fuera del alcance de la materia la modularización (funciones y
procedimientos formales) y los tipos de datos estructurados (arreglos,
matrices y registros). En Programación estructurada implementarás las
estructuras de esta unidad en un lenguaje formal.
