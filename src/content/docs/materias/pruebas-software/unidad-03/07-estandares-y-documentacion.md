## Estándares de referencia

| Estándar | Qué aporta a esta unidad |
| --- | --- |
| ISO/IEC/IEEE 29119-1 | Conceptos y vocabulario |
| ISO/IEC/IEEE 29119-2 | Procesos de prueba, enfoque basado en riesgos |
| ISO/IEC/IEEE 29119-3 | Documentación: plan, casos, reportes |
| ISO/IEC/IEEE 29119-4 | Técnicas: especificación, estructura, experiencia |
| IEEE 829-2008 | Documentación. Referencia histórica en la materia |
| ISO/IEC 25010 | Características de calidad para el alcance no funcional |

<p class="small">Un estándar se usa como referencia y vocabulario común, no se "aplica completo" en un proyecto académico.</p>

## Documentos de prueba

| Documento | ¿En esta unidad? |
| --- | --- |
| Plan de pruebas | Sí |
| Especificación de casos de prueba | Sí (anexos del plan) |
| Procedimiento de prueba | Unidades IV y V |
| Registro de ejecución | Se define en el plan. Se produce desde la Unidad IV |
| Reporte de incidente o defecto | Unidad VII |
| Reporte de resultados | Unidad VII |

<p class="small">La denominación exacta varía entre normas y ediciones.</p>

## Evidencias de ejecución

Una evidencia útil responde, sin preguntarle a nadie:

<div class="grid-3">

<div class="card"><strong>¿Qué?</strong><p>ID del caso.</p></div>
<div class="card"><strong>¿Cuándo y dónde?</strong><p>Fecha, versión y ambiente.</p></div>
<div class="card"><strong>¿Con qué?</strong><p>Datos utilizados.</p></div>
<div class="card"><strong>¿Qué se esperaba?</strong><p>Resultado esperado.</p></div>
<div class="card"><strong>¿Qué pasó?</strong><p>Resultado obtenido y veredicto.</p></div>
<div class="card"><strong>¿Quién?</strong><p>Persona que ejecutó.</p></div>

</div>

<p class="small">Una captura sin ID, fecha ni resultado esperado no es evidencia: es una imagen.</p>
