**RA relacionado:** RA1.1. **Contenido:** 1.1.1. **Modalidad:**
individual o grupal.

## Contexto

A partir de [1. Calidad de software](/materias/pruebas-software/unidad-01/01-calidad-de-software/)
(calidad de software y sus características observables).

## Instrucciones

1. Elige dos productos de software que uses con frecuencia
   (aplicaciones móviles, servicios web, herramientas de estudio o
   trabajo).
2. Para cada uno, identifica al menos tres características de calidad
   (funcionalidad, confiabilidad, usabilidad, eficiencia de
   desempeño, mantenibilidad, seguridad) que consideres presentes, y
   explica brevemente por qué.
3. Identifica al menos una característica que consideres deficiente
   en alguno de los dos productos, y explica qué evidencia concreta
   sustenta esa opinión (no basta con "no me gusta").
4. Relaciona una de las deficiencias identificadas con una posible
   etapa del ciclo de vida donde pudo haberse introducido (análisis,
   diseño, implementación o mantenimiento).

## Producto esperado

Notas de análisis con las características identificadas para ambos
productos y la relación con el ciclo de vida.

## Criterio de logro

Identifica correctamente al menos tres características de calidad
aplicadas a ejemplos reales, distingue una fortaleza de una debilidad
con evidencia concreta (no solo preferencia personal), y relaciona
correctamente una debilidad con una etapa plausible del ciclo de vida.
