Materia clave 19506, periodo V, área profesionalizante, Licenciatura en
Informática, Facultad de Informática Culiacán (UAS).

## Propósito

La materia tiene como propósito que conozcas y apliques diferentes
métodos, técnicas y herramientas para contribuir a la calidad del
software, comprendiendo la importancia de realizar pruebas sistemáticas
durante las diferentes etapas del desarrollo.

Las pruebas de software no se entienden aquí únicamente como una
actividad al final de un proyecto, sino como una práctica integrada al
proceso de desarrollo, orientada a reducir riesgos, detectar defectos,
validar requisitos y generar evidencia sobre la calidad del producto.

## Cómo está organizada la materia

La materia se organiza en ocho unidades, con una progresión desde los
fundamentos hasta la aplicación práctica y la integración profesional.

## Tu proyecto integrador

El proyecto integrador es el principal elemento de articulación
práctica de la materia. Tú eliges el sistema bajo prueba desde la
Unidad I, y ese mismo sistema te acompaña durante todo el semestre: vas
a definir requisitos y criterios de aceptación, construir un plan de
pruebas, diseñar y ejecutar casos de prueba, automatizar los que
corresponda, registrar defectos, generar métricas y cerrar con un
reporte final.
