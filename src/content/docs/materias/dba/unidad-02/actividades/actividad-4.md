## Requisitos antes de empezar

* Haber leído [3. Protección de datos sensibles](/materias/dba/unidad-02/03-proteccion-de-datos-sensibles/).
* Guía técnica: [Laboratorio 1](/materias/dba/unidad-02/laboratorios/laboratorio-1-proteccion-y-privacidad-de-datos/).

## Instrucciones para el estudiante

Analiza un conjunto de datos y determina:

1. clasificación
2. nivel de riesgo
3. usuarios que requieren acceso
4. datos que deben enmascararse
5. datos que podrían seudonimizarse
6. periodo de retención
7. mecanismo de eliminación

## Producto/evidencia

Una matriz de clasificación y protección.
