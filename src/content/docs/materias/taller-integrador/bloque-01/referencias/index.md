## Fuentes prioritarias del bloque

### REF-B1-01 — Schwaber y Sutherland, *The Scrum Guide*

| Campo | Valor |
| --- | --- |
| Autores | Ken Schwaber, Jeff Sutherland |
| Año | 2020 |
| Rol en el bloque | **Fuente principal de Scrum** |
| Relevancia | Muy alta |

Fuente principal para [3. Introducción a Scrum](/materias/taller-integrador/bloque-01/03-introduccion-a-scrum/)
(principios ágiles, roles, artefactos, eventos, historias de usuario) y
para el Product Backlog inicial de
[4. Definición del proyecto](/materias/taller-integrador/bloque-01/04-definicion-del-proyecto/).
La guía tiene prioridad sobre otras fuentes cuando exista diferencia
entre una explicación complementaria y la definición oficial de Scrum.

### REF-B1-04 — Hunt y Thomas, *The Pragmatic Programmer*

| Campo | Valor |
| --- | --- |
| Autores | Andrew Hunt, David Thomas |
| Año | 2019 |
| Editorial | Addison-Wesley |
| Rol en el bloque | Fundamentación del desarrollo profesional |
| Relevancia | Media-alta |

Fuente de contexto para

No se utiliza como fuente principal para definir Scrum.

## Recurso complementario específico de Scrum

### REF-B1-12 — SCRUMstudy, *SBOK Guide*, 5.ª edición (español)

| Campo | Valor |
| --- | --- |
| Organización | SCRUMstudy |
| Tipo | Recurso complementario |
| Relevancia | Alta |

Material complementario para la enseñanza de Scrum. **No sustituye** a
la *Scrum Guide* (REF-B1-01). Cuando exista diferencia entre una
definición del SBOK y la definición oficial de la Scrum Guide, prevalece
la Scrum Guide. Útil para ampliar explicaciones y ejemplos de
principios ágiles, roles, artefactos, eventos e historias de usuario.
