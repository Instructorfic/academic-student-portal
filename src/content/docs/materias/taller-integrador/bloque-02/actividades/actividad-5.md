**RA relacionado:** insumo para RA2.4. **Contenido:** 2.4.1, 2.4.2.
**Modalidad:** individual o grupal.

## Contexto

El error más frecuente al aplicar patrones de diseño es elegir uno
antes de tener un problema real. Esta actividad practica el orden
correcto antes del
[Laboratorio 3](/materias/taller-integrador/bloque-02/laboratorios/laboratorio-3-patron-de-diseno/).

## Instrucciones

1. Revisa la tabla de las tres familias de patrones en
   [5. Patrones de diseño](/materias/taller-integrador/bloque-02/05-patrones-de-diseno/).
2. Para cada uno de estos tres problemas hipotéticos, identifica qué
   familia de patrón lo resolvería y por qué:
   - un sistema que debe enviar la notificación de un préstamo vencido
     por correo, SMS o notificación push, según la preferencia del
     usuario;
   - un sistema que necesita crear distintos tipos de reporte (PDF,
     Excel, HTML) a partir de los mismos datos;
   - un sistema que debe avisar a tres módulos distintos cada vez que
     se aprueba un préstamo, sin que esos módulos sepan unos de otros.
3. No implementes código todavía: solo identifica la familia y
   justifica en una frase.

## Producto esperado

Tabla de tres filas: problema hipotético, familia de patrón
identificada, justificación breve.

## Criterio de logro

Identifica correctamente al menos dos de las tres familias (de
comportamiento para el primer y tercer caso, creacional para el
segundo) y justifica con el problema, no solo con el nombre del patrón.
