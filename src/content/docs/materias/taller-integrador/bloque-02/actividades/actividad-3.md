**RA relacionado:** RA2.5. **Contenido:** 2.2.3.
**Modalidad:** grupal.

## Contexto

En el Bloque I usaste una Definition of Done simple. Este bloque exige
una versión más exigente, que incorpore lo aprendido sobre ramas,
revisión y arquitectura.

## Instrucciones

1. Retomen la Definition of Done del Bloque I.
2. Agreguen, como mínimo, dos criterios nuevos relacionados con este
   bloque (por ejemplo: "pasó por code review", "sigue la organización
   documentada en `ARQUITECTURA.md`").
3. Redacten la versión final como una lista verificable, no como una
   descripción general.

## Producto esperado

Definition of Done actualizada del equipo, documentada en el repositorio
(puede vivir en el `README.md` o en un archivo `DEFINITION_OF_DONE.md`).

## Criterio de logro

La Definition of Done es una lista verificable (no frases vagas como
"queda bien hecho") e incluye al menos dos criterios nuevos propios de
este bloque.

> **Importante.** Completa esta actividad **antes** del
> [Laboratorio 1](/materias/taller-integrador/bloque-02/laboratorios/laboratorio-1-git-colaborativo/), no después, para poder
> aplicarla de verdad durante tus primeros pull requests.
